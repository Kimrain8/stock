## 三、智能分析中心

### 3.1 分析 Tab

1. 输入股票代码（如 `688508.SH`）
2. 场景可留空（自动判断），或指定 `高成长股` / `价值股` 等
3. 勾选"强制刷新"可忽略当天缓存
4. 点"🔍 开始分析"
5. 等待 50~90 秒（首次含数据抓取，后续命中缓存约 20~30 秒）
6. 报告自动展示在下方，同时保存到 `reports/`

**报告包含**：
- YAML frontmatter（评级 / 置信度 / 预测区间 / 规则应用）
- 规则应用（逐条核对历史规则）
- 投资结论
- 交叉验证
- 多空分析
- 核心风险提示
- 跟踪指标
- 操作建议

### 3.2 复盘 Tab

1. 输入股票代码
2. 点"🔄 开始复盘"
3. 系统自动：
   - 列出该股票所有历史报告
   - 判定每份报告是否到期
   - 对到期的报告：查实际股价 → 判定对错 → LLM 生成反思
   - 提取候选规则写入 `rules/_pending.md`

**判定逻辑**：
- 方向正确：buy 涨 / sell 跌 / hold 波动 ≤ ±10%
- 区间命中：实际收益在预测区间内
- 完全正确 / 部分正确 / 错误

### 3.3 规则库 Tab

- 展示 `global.md` 和场景规则
- 展示 `_pending.md` 待审核规则
- **一键采纳**：pending 规则点"✅ 采纳"直接迁移到正式规则
- **直接编辑**：点击"✏️ 编辑"，在弹窗内改 Markdown 后保存

## 四、趋势探索

### 4.1 交互方式

- **默认**：左键拖动 = 平移图表
- **框选**：点工具栏方框图标 → 左键框选日期范围 → 自动设置"向前汇总天数"
- **缩放**：滚轮缩放 x 轴
- **复位**：点击工具栏 reset 图标

### 4.2 三个图

| 图 | 内容 |
| :--- | :--- |
| ① | 成交量 / 成交额 / 换手率柱（底部对齐均价） |
| ② | 同上柱 + 从 0 开始，左轴数值右轴百分比 |
| ③ | 均价折线 + 最高/最低持续天数柱 |

**三图联动**：拖动/缩放任一图，其余两图同步。

### 4.3 汇总天数

- `0`：只看当天
- `N`：窗口为最近 N+1 天（含当天）
- 均价 = 窗口总成交额 / 窗口总成交量（VWAP，非算术平均）

## 五、选股扫描

### 5.1 配置规则

| 字段 | 说明 |
| :--- | :--- |
| 天数 | 窗口长度 |
| 涨幅 | 阈值（百分比） |
| 类型 | `natural`（自然日）/ `trading`（交易日） |

可添加多条规则，按顺序优先匹配。

### 5.2 输出模式

| 模式 | 说明 |
| :--- | :--- |
| `high` | 每只股票保留涨幅最大的段 |
| `end` | 保留 end_date 最晚的段 |
| `all` | 所有满足条件的日期都输出 |

### 5.3 结果操作

- 点击"查看"列的"打开 →"跳转到趋势页
- 支持表头筛选、排序
- 可导出 CSV

## 六、数据探索器

三栏布局：

- **左**：变量浏览器（列名/类型/非空数）
- **中**：表达式编辑器（Python + Pandas）
- **右**：结果面板（自动渲染表格/图表）

### 6.1 常用表达式

```python
df.tail(20)                     # 最近 20 行
df[df['close'] > 100]           # 筛选
df.describe()                   # 统计摘要
df.tail(60)                     # 自动画 K 线图
```

### 6.2 快捷键

- 编辑器修改后**失焦**自动执行
- 点击"快捷操作"按钮快速填充

## 七、常见问题

### 7.1 分析耗时多久？

- 首次分析：50~90 秒（含数据抓取）
- 命中缓存：20~30 秒（跳过抓取）
- 命中当天报告缓存：秒级

### 7.2 如何快速抓取多只股票数据？

```cmd
:: 批量预热缓存
pipenv run python scripts/warm_cache.py 688508.SH 002074.SZ 300750.SZ

:: 从文件批量
pipenv run python scripts/warm_cache.py --file watchlist.txt
```

### 7.3 规则库修改后如何生效？

- 规则文件修改后**自动生效**（下次分析时重新加载）
- 有内存缓存，可点规则 Tab 的"🔄 刷新"强制失效

### 7.4 报告保存在哪？

- `reports/{代码}_{名称}_{日期}.md`
- 反思汇总：`reports/lessons_learned/{代码}_{名称}_reflections.md`

### 7.5 缓存放在哪？

- `cache/data/{代码}.pkl`
- 手动清理：`pipenv run python scripts/clear_cache.py 688508.SH`
- 全部清理：`pipenv run python scripts/clear_cache.py --all`
