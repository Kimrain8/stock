# 条件模板库

> 把自然语言描述映射为 pandas 表达式。
>
> 格式：
> ```
> ## 模板名称
> - 模式：正则
> - 字段：语义名（引用 field_aliases）
> - 表达式：pandas 表达式，用 {col} 引用列名，{value} 引用值，{n} 引用数字
> - 描述：用于生成 reason 列
> ```

## 股价低于 X 元
- 模式：(?:股价|价格|收盘价|当前价|最新价|现价)低于\s*([\d.]+)\s*元?
- 字段：收盘价
- 表达式：df["{col}"] < {value}
- 描述：收盘价 < {value} 元

## 股价高于 X 元
- 模式：(?:股价|价格|收盘价|当前价|最新价|现价)高于\s*([\d.]+)\s*元?
- 字段：收盘价
- 表达式：df["{col}"] > {value}
- 描述：收盘价 > {value} 元

## 股价在 X-Y 元之间
- 模式：(?:股价|价格|收盘价)在\s*([\d.]+)\s*[-到~]\s*([\d.]+)\s*元?
- 字段：收盘价
- 表达式：(df["{col}"] >= {value1}) & (df["{col}"] <= {value2})
- 描述：股价在 {value1}-{value2} 元之间

## 换手率大于 X
- 模式：(?:换手率|换手)大于\s*([\d.]+)\s*%?
- 字段：换手率
- 表达式：df["{col}"] > {value}
- 描述：换手率 > {value}

## 换手率小于 X

- 描述：总市值 < {value} 亿

## 近 N 日涨幅大于 X%
- 模式：近\s*(\d+)\s*日涨幅?大于\s*([\d.]+)\s*%?
- 字段：收盘价
- 表达式：(df["{col}"] / df["{col}"].shift({n}) - 1) > {value} / 100
- 描述：近 {n} 日涨幅 > {value}%

## 近 N 日涨幅小于 X%
- 模式：近\s*(\d+)\s*日涨幅?小于\s*([\d.]+)\s*%?
- 字段：收盘价
- 表达式：(df["{col}"] / df["{col}"].shift({n}) - 1) < {value} / 100
- 描述：近 {n} 日涨幅 < {value}%

## 近 N 日跌幅大于 X%
- 模式：近\s*(\d+)\s*日跌幅?大于\s*([\d.]+)\s*%?
- 字段：收盘价
- 表达式：(df["{col}"] / df["{col}"].shift({n}) - 1) < -{value} / 100
- 描述：近 {n} 日跌幅 > {value}%

## 创 N 日新高
- 模式：创\s*(\d+)\s*日新高
- 字段：收盘价
- 表达式：df["{col}"] >= df["{col}"].rolling({n}).max()
- 描述：创 {n} 日新高

## 创 N 日新低
- 模式：创\s*(\d+)\s*日新低
- 字段：收盘价
- 表达式：df["{col}"] <= df["{col}"].rolling({n}).min()
- 描述：创 {n} 日新低
