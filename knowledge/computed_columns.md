# 计算列定义

> 从已有列推导出新的列。这些列可以在条件中直接引用。
>
> 格式：
> ```
> ## 列名
> - 表达式：pandas 表达式
> - 依赖：依赖的语义字段列表
> ```

## 20日涨幅
- 表达式：(df["{收盘价}"] / df["{收盘价}"].shift(20) - 1)
- 依赖：收盘价

## 60日涨幅
- 表达式：(df["{收盘价}"] / df["{收盘价}"].shift(60) - 1)
- 依赖：收盘价

## 5日均线
- 表达式：df["{收盘价}"].rolling(5).mean()
- 依赖：收盘价

## 20日均线
- 表达式：df["{收盘价}"].rolling(20).mean()
- 依赖：收盘价

## 60日均线
- 表达式：df["{收盘价}"].rolling(60).mean()
- 依赖：收盘价

## 量比
- 表达式：df["{成交量}"] / df["{成交量}"].rolling(5).mean()
- 依赖：成交量

## 20日振幅
- 表达式：((df["{最高价}"] - df["{最低价}"]) / df["{昨收价}"]).rolling(20).mean()
- 依赖：最高价, 最低价, 昨收价
